# Logic Gates

## Description
Verilog HDL implementation and simulation of basic logic gates.

## Logic Gates Implemented
- AND
- OR
- NOT
- NAND
- NOR
- XOR
- XNOR

## Simulation
The testbench applies all four possible input combinations:

A=0, B=0
A=0, B=1
A=1, B=0
A=1, B=1

The outputs are observed using the simulation waveform.
